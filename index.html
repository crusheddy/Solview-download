Installing
  1. Tap Download the app above and save the .apk file.
  2. Open it from your notifications or your Downloads folder.
  3. Android will ask permission to install from this source — allow it, then tap Install.
  4. Open Solview and sign in with the details you were sent.

This app is distributed directly rather than through the Play Store, so that warning is expected. Only install the file from this page.
